# I developed a machine learning model for my master's course in Business Intelligence to predict delivery delays for DataCo Global. Used Python for data cleaning, EDA, and model testing with Random Forest and Logistic Regression. Results demonstrate strong accuracy and offer recommendations to enhance supply chain performance.
*Business Problem: DataCo Global was experiencing high delivery delay rates (54%), causing customer dissatisfaction, order cancellations, and loss of sales. The company needed a way to predict late deliveries before they occurred and understand the key factors contributing to delays.
* Objective: Build a machine learning model to classify whether an order will be on-time or late, and generate data-driven recommendations to improve supply chain efficiency.
* Data Overview
Source: Kaggle DataCo Supply Chain dataset
Size: 180,519 records, 53 variables
Data contained product, customer, order, shipment, and delivery attributes
# Methods & Approach
1. Data Cleaning & Preprocessing
*Removed irrelevant or high-noise columns (customer info, product codes, zip codes, etc.)
*Handled redundancy and normalized data
*Encoded categorical variables for ML compatibility
